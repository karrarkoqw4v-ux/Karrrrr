# كويز تواصلكم (Android)

تطبيق تواصل ومحادثة اجتماعي بالعربية، بوضع داكن افتراضي: تسجيل دخول وإنشاء حساب بأربع خطوات، منشورات وقصص وريلز،
متابعة وإعجابات وتعليقات، دردشة ومكالمات (واجهة)، بروفايل وإعدادات.

- **التقنية:** Kotlin + Jetpack Compose + Material 3، واجهة RTL، خط IBM Plex Sans Arabic، حركات ضغط نابضة وانتقالات سلسة.
- **التصاميم:** `design/screens/*.png` (54 شاشة داكنة + لوحات). تُعاد بـ `python3 design/render.py`.
- **التحميل:** صفحة Releases (الوسم `quiz-apk-latest`)، يُبنى تلقائياً بـ GitHub Actions.

## حالة النسخة
البيانات **محلية على الجهاز فقط** (لا يوجد سيرفر): الحسابات (PBKDF2)، المنشورات، المتابعات، الرسائل.
ردود الأصدقاء تجريبية (بوت)، والمكالمات واجهة فقط (بدون صوت/فيديو حقيقي).
لتحويله لتطبيق متعدد المستخدمين: استبدل `app/src/main/java/iq/quiz/data/Repo.kt` بسيرفر (Firebase أو Supabase) وأضف WebRTC للمكالمات.
