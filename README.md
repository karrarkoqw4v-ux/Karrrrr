# مشروع لعبة عراقية

مشروع لعبة عراقية.

## الدخولية (شاشة البداية)

افتح `intro/index.html` بالمتصفح. التسلسل:
1. العلم العراقي يرفرف مع جمر ودخان، وعبارة "بلاد الرافدين".
2. ظهور شعار "لعبة عراقية" الذهبي بضربة مع وميض واهتزاز وصوت انفجار.
3. شريط تحميل مع نصائح، ثم زر "اضغط للدخول".

معاينة: `intro/preview/` (صور + فيديو).
