# مشروع لعبة عراقية

مشروع لعبة عراقية.

## الدخولية (شاشة البداية)

افتح `intro/index.html` بالمتصفح. التسلسل:
1. شرائح بألوان العلم العراقي تقطع الشاشة مع جمر ودخان وعبارة "بلاد الرافدين".
2. شعار "لعبة عراقية" الذهبي مع درع العلم، بضربة ووميض واهتزاز وصوت.
3. شريط تحميل ونصائح، ثم زر "اضغط للدخول".
4. اتصال بالخادم ثم اللوبي (اسم اللاعب، العملات، الأوضاع، زر ابدأ، شريط التنقل).

معاينة: `intro/preview/` (صور + فيديو).

## اللعبة (نسخة تجريبية قابلة للعب)

افتح `game/index.html` بالمتصفح (أو ابدأ من `intro/index.html` ثم "اضغط للدخول").
بدون تثبيت ولا إنترنت (المكتبة داخل `game/lib`)، وتعمل على الكمبيوتر والموبايل.

- **الجندي:** مكافحة الإرهاب بسترة وخوذة وNVG وبندقية M4A1 (كاتم + منظار هولوغرافي + قبضة + ليزر)، مبني بالكود.
- **اللوبي:** مشهد ثلاثي الأبعاد، ملف لاعب، عملات، مهام، شريط تنقل، اختيار الوضع والخريطة.
- **خريطة العراق:** 18 محافظة بحدودها الحقيقية (geoBoundaries). بغداد متاحة، والباقي "قريباً".
- **مود بغداد (باتل رويال فردي):** دجلة والجسور والكرخ والرصافة، نصب الشهيد، مرقد الكاظمين، برج بغداد، نخيل، سيارات، حواجز.
  15 عدواً، منطقة آمنة تتقلص، ذخيرة وإسعافات، خريطة مصغرة وبوصلة.
- **التحكم:** WASD + الفأرة، زر أيسر إطلاق، أيمن تصويب، R تعبئة، Shift ركض، Space قفز. على الموبايل: عصا وأزرار.

ملاحظة: شوارع بغداد مبنية إجرائياً بتخطيط مستوحى من المدينة وليست مأخوذة من خرائط حقيقية.
