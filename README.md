# مشروع لعبة عراقية

لعبة باتل رويال ثلاثية الأبعاد في بغداد — تعمل بالمتصفح وعلى الأندرويد (APK).

## التشغيل
- **المتصفح:** افتح `game/index.html` (بدون إنترنت، كل الملفات داخل المجلد).
- **الأندرويد:** نزّل `IraqiGame.apk` من صفحة Releases (الإصدار `apk-latest`). يُبنى تلقائياً عبر GitHub Actions (`.github/workflows/android-apk.yml`) من مجلد `android/`.

## المحتوى
- **شاشة البداية:** شخصيات واقعية متحركة، الدولة (العراق)، البنغ وقوة الإشارة والبطارية.
- **الشخصيات:** موديل جندي مُهيكل بحركات وقوف/مشي/ركض (`game/models/Soldier.glb`)، مصبوغ بأزياء مكافحة الإرهاب والفرقة الذهبية.
- **اللوبي:** البطل + فريقه، اختيار المنظور (أول/ثالث)، بطاقة الأسلحة، المهام، البحث عن سيرفر بذكاء اصطناعي.
- **الإعدادات:** الرسومات (توفير الطاقة، عالي الدقة، HDR، HDR10 / مرتفع، طاقة متوازنة، قوي / 90 إطار، 120 و165 مقفولة)، عناصر التحكم (3 تخطيطات + محرر لتحريك وتكبير الأزرار وحفظها)، الحساسية، الأصوات والتنبيهات، اللغة والمنطقة، الخصوصية، متقدمة (الدم، تأثير اللمس…).
- **التحميل:** 10 → 20 → 30 → 40 → 50 → 70 → 80 → 100%.
- **المود:** هبوط بالمظلة فوق **مطار بغداد الدولي** (مدرج، صالة ركاب، برج مراقبة، حظائر، طائرات)، ثم المدينة: دجلة والجسور، الكرخ والرصافة، بيوت عراقية يمكن دخولها، نصب الشهيد، مرقد الكاظمين، برج بغداد.
- **اللوت:** M4A1، AKM، Kar98k (منظار)، P92؛ ذخيرة 5.56/7.62/9؛ ضمادة، إسعاف أولي، حقيبة طبية، مشروب طاقة؛ سترة وخوذة.
- **القتال:** 15 لاعب ذكاء اصطناعي بأسماء عراقية، دم وبقع، مؤشر اتجاه الضرر، منطقة آمنة تتقلص، خريطة مصغرة، بوصلة.
- **التحكم:** كمبيوتر: WASD، الفأرة، R، H علاج، C جلوس، V منظور، 1/2، F التقاط. موبايل: عصا + أزرار قابلة للتخصيص.

## ملاحظات
- المدينة مبنية بالكود بتخطيط مستوحى من بغداد، وليست نسخة مطابقة للخرائط الحقيقية.
- حدود المحافظات الـ18 من بيانات geoBoundaries.
- موديل الجندي من أمثلة three.js (أصله Mixamo).
- اللعب الجماعي الحقيقي يحتاج سيرفر؛ حالياً السيرفر محلي بذكاء اصطناعي.
