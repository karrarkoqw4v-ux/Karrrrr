# هلا (Android)

تطبيق محادثة اجتماعي بالعربية (دخول وتسجيل، منشورات وقصص، دردشة ومكالمات، بروفايل وإعدادات).

- **Kotlin + Jetpack Compose + Material 3**، واجهة RTL وخط Tajawal، حركات ضغط نابضة وانتقالات سلسة.
- **التصاميم:** `design/screens/*.png` (54 شاشة + لوحات). تُعاد بـ `python3 design/render.py`.

## حالة النسخة
البيانات **محلية على الجهاز فقط** (لا يوجد سيرفر): الحسابات (PBKDF2)، المنشورات، الرسائل.
ردود الأصدقاء تجريبية (بوت)، والمكالمات واجهة فقط (بدون صوت/فيديو حقيقي).
لتحويله لتطبيق حقيقي متعدد المستخدمين: استبدل `data/Repo.kt` بسيرفر (Firebase أو Supabase) وأضف WebRTC للمكالمات.
